            iPhone'a kur

            1. Safari'de Manify sayfasını aç.
            2. Alt menüde Paylaş simgesine dokun.
            3. "Ana Ekrana Ekle" seçeneğini seç.
            4. Sağ üstten "Ekle"ye dokun.
            5. Manify artık ana ekrandan uygulama gibi açılır.

            Bilinen sınırlamalar

            • Arama, resmi YouTube Data API v3 üzerinden yapılır; ücretsiz kota günlük olarak sınırlıdır (kota dolarsa arama ertesi gün otomatik sıfırlanır).
            • Oynatma, YouTube'un kendi web oynatıcısı (IFrame Player) üzerinden yapılır — bağımsız bir ses motoru değildir.
            • iOS Safari; otomatik oynatmayı, ekran kilitliyken sesin sürmesini ve arka plan oynatmayı kısıtlayabilir.
            • Bu sürüm kişisel/tek kullanıcı için tasarlanmıştır; API anahtarı `app.js` içine gömülüdür ve favoriler/geçmiş/kuyruk yalnızca bu cihazda saklanır.
